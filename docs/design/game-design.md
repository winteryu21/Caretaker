#### M1 퍼즐 상세

**설계 의도:** 두 플레이어가 같은 장소(변전실)에서 서로 다른 시간대의 정보를 교환해야 전력을 복구할 수 있다. 미래 플레이어는 수십 년 후의 배선 상태를 관찰하고, 과거 플레이어는 그 정보를 바탕으로 올바른 스위치를 조작한다.

```
[미래] 변전실 도착 → 차단기 패널의 배선 상태 관찰 → 과거에게 정보 전달
    ↕ (무전기)
[과거] 변전실 도착 → 메인 레버 올림 → 차단기 패널 스위치 조합 입력
    ↓ (인과)
[미래] 전력 복구 → 1층 조명/보안 시스템 가동
```

| # | 시간대 | 행동 | 시스템 이벤트 |
|---|:------:|:-----|:------------|
| 1 | 미래 | 변전실 이동, 예비 배터리+케이블 수집 | `AcquireItem(ITEM_BATTERY)`, `AcquireItem(ITEM_CABLE)` |
| 2 | 미래 | 보조 전력 장치에 배터리 사용 | `UseItemOnTarget` → 차단기 패널 최소 전원 공급 |
| 3 | 미래 | 차단기 패널 관찰 → 배선도 확인 | 조사 → 텍스트/이미지 UI 표시 |
| 4 | 미래→과거 | 무전기로 배선 정보 전달 | 음성 소통 (시스템 개입 없음) |
| 5 | 과거 | 변전실 이동, 메인 전력의 패널 관찰 | `CausalTrigger(CR_P1_POWER_LEVER)` |
| 6 | 과거 | 차단기 패널 고장난 배선과 정상 배선 간의 연결 해제 | `CausalTrigger(CR_P1_POWER_PANEL)` — 조건: 연결 끊김 x, 미래의 고장난 배선과 정상 배선간의 연결 x |
| 7 | 미래 | 전력 장치에 케이블 연결, 패널 관찰 후 해당 순서대로 전력 장치 레버 올림 |  |
| 8 | 미래 | **환경 변화**: 1층 조명 점등, 보안 시스템 가동 | `CausalReceiver` → 환경 상태 변경 |

**실패 시나리오:**

| 실패 | 결과 |
|------|------|
| 잘못된 배선 연결 | 소음 발생 → 과거 변전실 인근 AI 경보 |
| 배터리 없이 패널 조작 | "전원이 공급되지 않습니다" 피드백 |
| 잘못된 스위치 순서 | "순서가 올바르지 않습니다" 피드백 |

**설계 의도:** 미래 플레이어가 수십 년간 방치된 보안 시스템의 취약점을 발견하고, 과거 플레이어가 그 취약점을 이용해 네트워크에 침입한다. 정보의 방향이 M1과 반대(미래→과거).

```
[과거] 보안실 침입 → 터미널 접속 시도 → "보안 코드 필요" → 미래에 요청
    ↕ (무전기)
[미래] 보안실 이동 → 노후화된 보안 터미널 조사 → 취약점 코드 발견 → 과거에 전달
    ↕ (무전기)
[과거] 취약점 코드 입력 → 네트워크 접속 → 인사 기록 확인 (카드키 소지자)
```

| # | 시간대 | 행동 | 시스템 이벤트 |
|---|:------:|:-----|:------------|
| 1 | 과거 | 보안실 진입 | 자유 진입 (열쇠 불필요) |
| 2 | 과거 | 보안 터미널 접속 시도 | 조사 → "보안 코드가 필요합니다" |
| 3 | 과거→미래 | 무전기로 도움 요청 | 음성 |
| 4 | 미래 | 보안실의 노후 터미널 조사 | 조사 → 취약점 코드 텍스트 표시 |
| 5 | 미래→과거 | 취약점 코드 전달 | 음성 |
| 6 | 과거 | 터미널에 코드 입력 | `CausalTrigger(CR_P1_SEC_HACK)` |
| 7 | 과거 | 인사 기록 열람 → 카드키 소지자=연구소장 확인 | 조사 → 텍스트 UI |

```
[과거] 자료실 진입(카드키) → 청사진 후보 3개 발견 → 각각의 조합 매뉴얼 읽음 → 미래에 전달

[미래] 실험실 진입 → 조합 실험 수행 → 발생 현상 관찰 → 과거에 전달
```

#### M4 퍼즐 상세

**설계 의도:** 미래 플레이어는 해킹 지식이 있지만, 미래의 접근 터미널이 고장나 있어 직접 바이러스를 설치할 수 없다. 대신 과거 플레이어에게 해킹 힌트를 전달하고, 과거가 그 힌트를 바탕으로 바이러스 퍼즐을 완성한다. 과거가 심어 둔 타이머 바이러스가 수십 년 후 미래에서 작동하여 실린더 잠금이 해제된다.

```
[미래] 저장고 도착 → 접근 터미널 고장 확인 → 해킹 힌트를 과거에 전달
    ↕ (무전기)
[과거] 저장고 이동 → 미래의 힌트에 따라 바이러스 퍼즐 완성 → 타이머 설정
    ↓ (인과: 수십 년의 시간 경과)
[미래] 실린더 잠금 해제 → 올바른 실린더 선택 → 입자 회수
```

| # | 시간대 | 행동 | 시스템 이벤트 |
|---|:------:|:-----|:------------|
| 1 | 양쪽 | 저장고(B동 1F) 이동, 실린더 보관함 확인 | — |
| 2 | 미래 | 접근 터미널 조사 → "터미널이 고장났습니다" | 조사 → 피드백 |
| 3 | 미래→과거 | 해킹 힌트 전달 (바이러스 코드 구조, 입력 순서 등) | 음성 |
| 4 | 과거 | 터미널에서 미래의 힌트에 따라 바이러스 퍼즐 입력 | `CausalTrigger(CR_P2_VIRUS_PLANT)` |
| 5 | 미래 | 실린더 잠금 해제 확인 | `CausalReceiver` → 실린더 개방 |
| 6 | 미래 | 올바른 실린더 선택 → 입자 회수 | 상호작용 → M4 완료 → Phase 3 진입 |

**설계 메모:**
- 미래 터미널이 고장난 이유: 수십 년간의 부식/손상. 미래만이 해킹 구조를 이해하고 있다는 설정.
- 과거 터미널은 정상 작동하지만 과거 플레이어에게 해킹 지식이 없어 미래의 안내가 필수.
- 올바른 실린더 선택은 M3에서 확보한 청사진 정보 기반.

| 높은 플랫폼 | 미래 | **인과** | 과거가 플랫폼 장치 조작 / 플랫폼이 위아래로 움직여서 타고갈수있음
(`CR_P3_PLATFORM_LOWER`) → 미래에서는 무너진 잔해위에 무너진 플랫폼이 생김(접근 가능) |

**구간 3: 출구**

| 장애물 | 시간대 | 유형 | 해결 방법 |
|--------|:------:|:----:|:---------|
| 최종 봉쇄문 | 양쪽 | **동시** | 양쪽이 동시에 잠금 해제 장치 조작 → 문 개방 / 잠금 해제 이후 긴박감을 위해 10번 상호작용키 클릭시 열리고 탈출 성공하게 | 
| AI 최종 추격 | 양쪽 | 개인 | 대시로 출구 도달 |
| 첫번째 봉쇄문 | 양쪽 | 과거 | 미래에서는 레버가 내려져있음 -> 알맞게 과거가 레버를 내리면 문 개방 |
| 무너진 잔해 | 양쪽 | 과거 | 대시 및 웅크리기로 피하기 |
| 밞으면 발판이 무너짐 | 미래 | 인과 | 과거가 특정 플랫폼을 밞으면 미래에서는 갑자기 그 플랫폼이 사라짐 |

**정보 흐름 (미래→과거):**

| 미래가 아는 것 | 과거에게 전달 | 과거의 행동 |
|:-------------|:------------|:----------|
| "미래에만 레버 4개중 2개가 내려가있음" | 무전기 | 과거는 알맞은 레버를 똑같이 내려야함 |
| "천장이나 플랫폼이 무너져있다. (무너지는 유형을 미래가 과거에게 알려줘야함)" | 무전기 | 대시로 or 웅크리기를 통해 회피 |



**판정:**

| 조건 | 결과 |
|------|------|
| 양쪽 모두 출구 도달 | **탈출 성공** → 결과 화면 |
| 한쪽이라도 AI에 포획 | **공동 실패** → 해당 구간 체크포인트(CP_P3_0X)로 복귀 |
| 타임아웃  | **공동 실패**  어차피 잡히면 타임아웃|
