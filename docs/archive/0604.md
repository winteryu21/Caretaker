# 개요
- 계획된 아키텍처가 방대하여 이해가 어렵고 개발 흐름을 놓쳤다. 팀 전체의 이해를 다시 정상화하기 위한 작업이다.
- 현재 진행 가능한 전체 게임 흐름을 파악하고, 
- 어떤 부분이 병목인지, 해당 병목을 해결하려면 어떤 클래스가 구현되고 연결되어야 하는지, 
- 전체 아키텍처가 어떤 식으로 연결되어 있는지 분석하고, 현재 구현된/구현 예정인 클래스와 SO 간 어떤 방식으로 연동되어야 하는지 등을 가독성 좋고 이해하기 쉽게 안내한다.

# 원하는 Game Flow

## 플레이어 접속
> 이건 확인됨
- 두 플레이어가 각각 Host-Client 배정
- Past, Future 배정
- Both Ready -> 각자의 Scene 로드 및 플레이 시작
